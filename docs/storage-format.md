# 磁盘存储格式（v1）

## 目录布局

```
<root>/
├── format.json              # 格式版本标记：{"version":1}
├── chunks/
│   └── <shard>/             # 取地址摘要前 2 个十六进制字符，共 256 个分目录
│       └── sha256-<hex>     # 分块字节，文件名即内容地址
├── manifests/
│   └── <shard>/
│       └── sha256-<hex>     # 清单 JSON，文件名即 CID
├── refs/
│   └── <hex(name)>.json     # 命名引用（pin），文件名是引用名的十六进制
├── tmp/                     # 原子写临时文件；崩溃残留由 GC 按宽限期清理
└── quarantine/              # 被隔离的损坏/未知文件（带时间戳与随机后缀）
```

- 分目录按地址摘要前 2 个十六进制字符分片，避免单目录文件过多。
- 引用名整体十六进制编码，从根本上杜绝路径穿越与非法文件名字符。

## 引用文件格式（refs/&lt;hex&gt;.json）

```json
{
  "version": 1,
  "name": "report/2026-09.pdf",
  "addr": "sha256-...",
  "created": "2026-09-17T08:00:00.123456789Z"
}
```

## 原子性与崩溃安全

- 所有内容/引用写入都走“写 `tmp/` 随机文件 → `rename` 到目标路径”，
  并对父目录 `fsync`；崩溃只会留下 `tmp/` 残留，不会产生半写入对象。
- 内容提交采用 **“先全部分块，最后清单”** 的顺序。
  清单可见即表示其全部分块已就位（GC 无法在两者之间插入，见[回收文档](retention-and-gc.md)）。
- 去重提交 `commitIfAbsent` 先 `stat` 目标：已存在则复用，绝不覆盖。

## 损坏与未知文件

- 读取路径上哈希不符的分块/清单立即移入 `quarantine/`。
- GC 扫描时对**所有**现存分块做哈希复核：
  - 哈希不符 → 隔离分块，并把引用它的所有清单一并隔离（避免“清单在但内容坏”）；
  - 文件名不是合法地址 → 隔离为 unknown；
  - 不被任何现存清单引用且哈希正确 → 作为可安全回收的孤儿删除；
  - GC 末尾做一次一致性补扫：引用了缺失分块的清单也会被隔离。
- 隔离文件可按 `QuarantineTTL` 过期清理（默认 24h，负数永久保留）。

## 历史数据兼容

- 根目录 `format.json` 记录格式版本；`Open` 时：
  - 不存在 → 按 v1 初始化目录并写入版本标记；
  - 存在且版本为 1 → 直接挂载，并通过扫描 `chunks/`、`manifests/` 校准用量，
    **历史数据无需重建**即可继续读写；
  - 版本不兼容 → 返回明确错误，不做破坏性处理。
- 用量记账（`usageCommitted`）在打开与每次 GC 后都以磁盘扫描为准校准，
  不会因历史异常或崩溃而漂移。

## 容量计量

- `MaxBytes` 统计 `chunks/` 与 `manifests/` 下已提交字节（真实占盘）。
- `tmp/`、`refs/`、`quarantine/` 不计入容量预算。
